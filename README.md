# bolsa-empleo-MOVIL
Visión del producto
Para los estudiantes de UNIPAZ que necesitan encontrar oportunidades laborales compatibles con sus horarios académicos y requieren ingresos para cubrir sus gastos, Bolsa de Empleo UNIPAZ es una aplicación móvil de intermediación laboral que permite consultar, publicar y gestionar ofertas de empleo adaptadas a la disponibilidad de los estudiantes. A diferencia de buscar oportunidades de manera dispersa en redes sociales, grupos, contactos personales o diferentes sitios web, nuestro producto centraliza las ofertas laborales dirigidas a estudiantes de UNIPAZ y facilita la conexión entre estudiantes y empleadores de Barrancabermeja.

Objetivo del Producto
Lograr que los estudiantes de UNIPAZ puedan encontrar y postularse a ofertas laborales compatibles con su disponibilidad académica desde una aplicación móvil, facilitando la conexión con empleadores de Barrancabermeja
