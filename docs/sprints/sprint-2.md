# Sprint 2 — Fundamentos y autenticación

**Duración:** días 1–5

## Objetivo

Establecer la base de autenticación y conexión de la aplicación con la API, habilitando el acceso inicial según el rol del usuario.

## Trabajo planificado

- **EV-01:** desarrollar la página principal.
- **EV-02:** implementar el registro empresarial.
- **EV-03, EV-04 y EV-05:** implementar la autenticación y la gestión de sesión.
- **EV-29:** desarrollar el perfil administrativo.
- Preparar la base de la API y la validación de roles.
- Preparar y ejecutar las pruebas iniciales de conexión con React Native.

## Entrega del sprint

Acceso funcional por roles, registro empresarial y conexión inicial entre la aplicación móvil y la API.
